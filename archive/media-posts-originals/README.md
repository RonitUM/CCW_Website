# Media-post originals (uncompressed)

Uncompressed originals of the click-to-enlarge media-post images, kept for
revert. The compressed versions served on the site live under
`public/media-posts/*/original/` (PR #30). Nothing here is served or bundled:
this folder is outside `public/`, so it does not affect the deployed site.
To revert an image, copy it back over its `public/media-posts/...` path.
